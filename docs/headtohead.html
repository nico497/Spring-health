How this works, and what it doesn't cover yet

  • Forced-pick question: "If you had to pick one employee mental health benefit for an HR team to offer, Spring Health or {rival}?" Asked in both name orders, 5 fresh runs each (60 answers total), via the OpenAI API (gpt-4o) directly, with a system prompt forcing a decisive pick.
  • Open comparison question: "Spring Health vs. {rival}: which should I choose?" Asked once per order (12 answers), no system prompt — this is where the qualitative reasoning below comes from. It is not repeated, so a single odd answer could be noise. The API route has no browsing, so none of these answers carry citations — they're the model's general knowledge, not a sourced comparison.
  • Both orders are asked because the model can lean toward whichever brand is named first. For Headspace for Work, Calm Business, Talkspace for Business and TELUS Health (LifeWorks) it barely matters — Spring Health wins 8 or 10 of 10 either way. Lyra Health is a clean, stable loss in both orders (1 of 5 each way) — not an order effect, just a consistent loss. Modern Health is the real coin-flip: 3 of 5 one way, 2 of 5 the other.
  • The headline finding: Spring Health is not a clean sweep. The model consistently favors Lyra Health on clinical quality and outcomes, and treats Modern Health as a genuine toss-up on holistic, global-reach positioning — the other four wins are real but less interesting than those two losses/near-losses.
  • Not yet covered: pricing, integrations, onboarding, setup and support as separate scored dimensions — they'd need their own repeated, structured prompts to be real rather than invented. Also not covered: any run through the ChatGPT web app, and any run while logged in.
